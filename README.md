# Mortah.logistic
Mortah Logistics System

An integrated logistics and delivery management platform for Mortah.

Overview

Mortah is a logistics company serving online stores, businesses, and shipping partners across Syrian governorates.

The goal of this project is to build a centralized platform for managing orders, deliveries, shipping operations, customer communication, and financial settlements.

Main Modules

- Admin Dashboard: Manage operations, users, pricing, delivery zones, reports, and system settings.
- Merchant Dashboard: Create orders, track deliveries, review balances, and manage customer information.
- Driver Dashboard: View assigned orders, update delivery statuses, and record cash collections.
- Order Management: Handle local deliveries, inter-governorate shipping, returns, and exchanges.
- Financial Management: Track collection on delivery (COD), merchant balances, driver settlements, commissions, and multiple currencies.
- Shipping Management: Manage shipping partners, destinations, shipping rates, and door-to-door delivery.
- Reporting and Analytics: Monitor delivery performance, revenue, costs, and operational efficiency.

Key Requirements

- Arabic-first interface with right-to-left (RTL) support.
- Responsive design for desktop and mobile devices.
- Role-based access control and secure authentication.
- Configurable delivery zones and pricing tables.
- Order status tracking and delivery time windows.
- Exportable reports and spreadsheet support.
- WhatsApp-friendly workflows and customer notifications.
- Support for Syrian pound (SYP) and US dollar (USD).
- Maintainable architecture with clear separation between frontend and backend.

Technology and Development

The system will be developed from scratch, using Google AI Studio as an AI-assisted development tool.

The final technology stack, database, authentication method, integrations, and deployment environment will be selected and documented during the technical planning phase.

Development Roadmap

1. Define business requirements and user roles.
2. Design the database and system architecture.
3. Build authentication and role-based dashboards.
4. Implement order management and delivery workflows.
5. Implement accounting, collections, and settlements.
6. Add shipping integrations, notifications, and reports.
7. Test security, accuracy, and operational workflows.
8. Deploy the system and prepare documentation.

Project Status

Status: Initial planning and requirements definition.

This project is under active development. Features and implementation details may change as requirements are finalized.

Security

- Never commit passwords, API keys, access tokens, or production credentials.
- Store secrets in environment variables.
- Restrict access to sensitive customer and financial information.
